El seguimiento

Un acompañamiento pensado para ti

Cada proceso es diferente: algunas vienen solas para comprender mejor su ciclo, otras en pareja para la planificación familiar o por problemas de infertilidad. El acompañamiento se adapta a tu situación y tus objetivos.

  • — Aprendizaje estandarizado y profesional
  • — Sesiones individuales de seguimiento
  • — Acompañamiento personalizado según tus necesidades y objetivos
El desarrollo

El camino del método Creighton

Las primeras cuatro sesiones de seguimiento se realizan con dos semanas de intervalo. La quinta tiene lugar un mes después, y las tres siguientes se programan con una separación de tres meses entre sí. Este calendario puede adaptarse a las necesidades particulares de cada cliente. Hemos comprobado que realizar un seguimiento frecuente al principio ayuda a aprender el sistema y a adquirir rápidamente confianza en su uso.

Después del primer año, cuando el cliente o la pareja ya se siente cómoda y segura utilizando el sistema, se recomienda realizar un seguimiento cada seis meses o una vez al año.

También se puede solicitar una cita de seguimiento en cualquier momento si cambian las necesidades del cliente. Mientras tanto, el/la Profesional de FertilityCare está disponible para resolver dudas y ofrecer orientación.
